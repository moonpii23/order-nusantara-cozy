## 2. ABOUT US SECTION
**Visual:** Foto interior kedai yang hangat atau foto proses penyeduhan manual (*manual brew*).

* **Header:** Tentang Kami
* **Judul Utama (H2):** Menghubungkan Rasa, Melestarikan Tradisi
* **Deskripsi:** 
  Didirikan pada tahun 2020, **Kopi Nusantara** lahir dari kecintaan kami terhadap keberagaman kopi Indonesia. Kami bermitra langsung dengan para petani lokal dari Aceh hingga Papua untuk menyajikan biji kopi *single-origin* pilihan berkualitas tinggi. 
  
  Kami percaya bahwa kopi bukan sekadar minuman, melainkan media untuk merayakan keberagaman dan kehangatan kebersamaan.

**Poin Keunggulan Kami:**
* 🌾 **100% Biji Kopi Lokal:** Dipetik dari perkebunan terbaik di seluruh Indonesia.
* 🔥 **Freshly Roasted:** Biji kopi disangrai secara teratur untuk menjaga kesegaran rasa.
* 🤝 **Direct Trade:** Mendukung kesejahteraan petani kopi lokal secara berkelanjutan.
